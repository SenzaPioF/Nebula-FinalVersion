# 🌌 NEBULA - Voice Interface AI

Un'interfaccia vocale futuristica basata su intelligenza artificiale. Parla con Nebula e lasciati sorprendere!

## ✨ Caratteristiche
- 🎤 Riconoscimento vocale in tempo reale
- 💬 Risposte IA tramite Groq (veloce e intelligente)
- 🖼️ Generazione immagini e video
- 📷 Analisi visiva tramite fotocamera
- 📎 Allegati: PDF, Word, Excel, immagini
- ⏱️ Timer e comandi rapidi
- 🌈 Temi colore personalizzabili

## 🚀 Come usarla
1. Apri https://[USERNAME].github.io/Nebula-FinalVersion/
2. Premi il microfono e parla
3. Aggiungi la tua chiave API Groq dalle impostazioni

## 📱 Funziona su
- Chrome/Edge desktop
- Chrome/Edge Android
- Safari (parziale)

## 🔧 Installazione locale
Clona il repo e apri `index.html` nel browser.
